# LandBridge AI

## Building Trust Into Nigerian Real-Estate Discovery

**Role:** Senior Lead Product Manager  
**Market:** Nigeria — Lagos, Abuja and Port Harcourt

### Problem

Real-estate discovery can be affected by fake listings, fraud, informal rental processes and uncertainty about whether a listing, agent or property can be trusted.

### Product Vision

An AI-enabled real-estate marketplace and SaaS ecosystem covering:

- Property discovery and search
- Trust and fraud controls
- AI Concierge
- Agent CRM
- Payments / escrow
- Developer CRM

### Trust & Verification

The product direction includes:

- Government ID verification
- CAC/business verification where relevant
- Property ownership verification
- Fraud/trust signals
- Structured agent workflows

### Roadmap Focus

**Q3 — Marketplace & Search**

**Q3–Q4 — Trust & Verification**

### What I Did

**Problem framing → product strategy → module definition → trust model → marketplace scope → roadmap → requirements**

### Outcome

The product scope was structured around marketplace discovery and a differentiated trust layer, with verification positioned as a core capability.

Measured marketplace adoption or fraud-reduction results are not claimed.

### Learning

For high-trust marketplaces, trust should be designed into discovery, listing, verification, transaction and post-transaction rather than added only as a compliance feature.
