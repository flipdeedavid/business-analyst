## How I Use Them

**Jira** — backlog management, user stories, acceptance criteria and delivery tracking.

**Trello / ClickUp / Asana** — workflow management, planning and team coordination.

**Figma** — product/interface collaboration and wireframing.

**Miro** — workshops, journeys, discovery and collaborative mapping.

**draw.io** — process maps, flows and workflow visualisation.

**Google Sheets** — analysis, prioritisation, surveys and data management.

**MS Project** — project planning and scheduling.

**MS Office** — requirements, reports, presentations and stakeholder documentation.
